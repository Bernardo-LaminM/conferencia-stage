⚡ Extração Direta via REST API do Power BI

Executa a query DAX diretamente no dataset AD HOC 80 da P&G através da API oficial da Microsoft (executeQueries).

💡 Não possui um Bearer Token neste momento?
Como o Power BI corporativo é protegido pela Microsoft, a chamada direta sem token retorna HTTP 403 Forbidden. Você não precisa se preocupar com tokens: basta copiar os dados do Power BI e colar na Aba 2, ou soltar a planilha do AD HOC 80 na Aba 3!
💡 Nota: Em navegadores padrão, chamadas diretas sem token ou com CORS restrito exibirão o diagnóstico com instruções no log.
